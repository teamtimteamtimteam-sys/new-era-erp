## 2a · `processing_runs` / `_inputs` / `_outputs` 今天建的是什么

* `processing_outputs` 一行 = 产出了哪个批次多少;`output_batch_id` **NOT NULL**;

## 2b · 物料平衡:今天有没有任何东西断言"进 = 出 + 损耗"

**【码】没有。唯一的平衡断言是一条【不等式】。**
`db/functions/commit_processing_run.sql:182`:

```sql
IF v_total_output > v_total_input THEN
    RAISE EXCEPTION 'OUTPUT_EXCEEDS_INPUT|%|%', v_total_output, v_total_input;
```

而 `loss_qty` 在 `:192` 是:

```sql
COALESCE(p_loss_qty, v_total_input - v_total_output)
```

* **调用方传什么就是什么。** 唯一的守卫是 `LOSS_NEGATIVE`(`:103–104`,不许为负);
* **`loss_qty` 与 `总投入 − 总产出` 【可以不相等而无人过问】** ——
  **【码】线上实测:10 张 committed 单里 0 张不相等。**
  **但那是因为调用方全部走了默认路径,不是因为有东西拦。**
  **这个 0 是【今天没人试过】,不是【试了会被拒】** —— 两者在报告里长得一样,
  而只有后者是一道闸。

> **数字不一致时它做什么:什么都不做。** 它不是一道闸,它是一个被相信的入参。

# 第三部分 · Tim 的工艺路线,以及它对模型的四条约束

> **【Tim】这是 brief 写完之后补上的地面事实,是 Tim 自己对产线怎么跑的陈述。
> 它【不是】对 schema 的测量,本刀【不建其中任何一部分】。**
> 它在这里的唯一用途:**拿来考验候选形状能不能表达现实。**

## 路线本身

1. 进料被**分类**:能不能深度放电?**这个判断在【采购时】做出,在货到之前。**
2. 能:**深度放电**(专用设备)→ **人工拆解到模组** → 模组拆解到**电芯**。
3. 电芯进**自动开壳机**(壳体与内容物分离),内容物进**极片分离机**,
   分成**正极片 / 负极片 / 隔膜**。
   **【Tim】开壳与极片分离之间没有额外的中间工序 —— 但电芯与极片【本身】
   就是这条线真实的中间产品。**
4. **电解液:目前计划挥发掉。** 它既不是产品也不是废物收据 ——
   **它是【消失掉的质量】**。环保设备可能后加。
5. 正极片可进**极片粉料线**;负极片可**修复**,也可粉化。
6. **旁路:** 放不了电的包、模组、3C 电池、破损电池 → **电池粉料线**。
   **【Tim】这与极片粉料线是【不同的设备】,因此是两道不同的工序,不是一道。**

## F1 · **路线是一棵树,不是一条线**

分类结果决定走哪条路。**(A)** —— 这是物理,不是选择。

**【码】今天说不出口。** 没有工序类型就没有"下一道工序"这个概念,
更没有"按分类结果分叉"。今天 13 张单每一张都是一个**无类型的原子事件**,
系统看不出哪张是放电、哪张是破碎。

## F2 · **形态是入口,不是"我们流程的第 N 步"** —— **而这一条有一半已经建好了**

**【Tim】料可以以整包、模组、电芯、【已开壳的电芯】、甚至【极片】的形态进厂,
因为这些【都可能被采购】。所以形态不是"我们流程的第 N 步":
买进来的极片与我们自己产的极片是【同一种东西】,必须走同一条下游路。**

### **Q1 · 那些形态是一条【有序的链】,还是一个【无序的集合】?** ★ 本刀最要紧的一问

整包 / 模组 / 电芯 / 已开壳电芯 / 正极片 / 负极片 / 隔膜 / 粉料 ——
**每一道工序是把料沿着一条固定的链【往前挪一格】,
还是每一道工序都必须【自己声明】它收什么、出什么?**

**它挡住什么:**
* **有序链** → **"这批料进不进得了这台机器"是【推导出来的】** ——
  一条判据管全部,而 `material_forms.implies_dismantling` 那一列
  (**【码】已经存在,6 行里 4 行为 true**)已经是这条链的**一个半成品**。
* **无序集** → **每一道工序都要自带一张"可接受投料"表**,
  路由从"一条链"变成"一张 N×M 的关系表"。
* **第 1 件(工序字典与路由)的形状【直接由它决定】**,而第 3 件(WIP)、
  第 7 件(放电)排在它后面。**它是本模型的第一块砖。**

### **Q2 · 隔膜、电解液、壳体是链上的【位置】,还是链的【出口】?**

它们不再往下走(隔膜、壳体去处置或外售;电解液挥发掉)。
**它们是"链的第 N 格",还是"从链上岔出去的出口"?**

**它挡住什么:** Q1 的答案形状(一条链装不装得下三个岔口)·
第 6 件里 **W2-(iii)"负价值产出"** 的建法 · F3 的多产出路由。
**电解液尤其:它是唯一一个【不产生任何批次】的出口(挥发),
而今天它只能进 `loss_qty`。**

### **Q3 · `output_batches.state` 变字典(G29),要不要提到这个模型【前面】?**

**它挡住什么:** **形状 (i) 的代价高低**(第五部分)。

### **Q4 · 一炉 = 一台机器,还是一条线?**(`proc-reality.md` **U4** 仍开)

自动开壳机 + 极片分离机是**两台设备**(【Tim】"没有额外中间工序"),
但它们可能**连成一条线连续跑**。**一张加工单记一台机器,还是记那条线?**

**它挡住什么:** 第 2 件(时长 —— 一条线的起止 ≠ 一台机器的起止)·
第 1 件(线算一道工序还是两道)· `processing_runs.equipment_id` 是不是够用
(**【码】它今天是单值、可空,线上 0/13 有值**)。

# 第八部分 · 建议的刀量

## 建议:**先建那件小的,其余等真炉次与 Tim 的答案**

**理由是测量,不是谦虚:**

1. **七件里,能现在建得对的只有一件。**
   第 1/3 件等 **Q1/Q5**(未问)· 第 4 件的量等 **U5**(产线)·
   第 5 件**整件**等 **U5** · 第 2 件不等人**但单独做价值很低** ·
   第 7 件是第 1 件的一行数据。**只有第 6 件是"答一个问题就能开工"。**
2. **第 6 件是唯一一件今天正在【产生一个错数】的。**
   其余六件是**沉默**(说不出口);第 6 件是**发声而且说错**
   —— 回收率拿一个把三件事塌在一起的数去算(2b + W2 + F4)。
   **沉默不会传染,错数会:它已经污染四个互相印证的数字。**
3. **它的数据代价是零。** 线上 13 张加工单全是测试数据(重测确认)。
4. **而 F3 刚刚把它变得更急:** 电解液挥发是**计划中的**、
   **第一条产线上就有的** W2-(i)。它从"将来可能有"变成了"设计里写着"。
