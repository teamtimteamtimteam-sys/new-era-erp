## 5 · T3 · `/finance/company` 与 `/me` —— 390px 上的 27px 横滚,修好了

### 3.1 ★ 先量清楚那 27px 是怎么来的(改前,390px)

| | `/finance/company` | `/me` |
|---|---|---|
| 整页 | `scrollWidth` **417** / `clientWidth` **390** → 溢出 **27** | 同 |
| **元凶** | `<input type="file" name="logo">` | `<input type="file" name="avatar">` |
| 那颗钮自己 | 宽 **350** · **`min-content` 350** · `max-width: none` | 宽 **350** · **`min-content` 350** |
| 它的祖先链 | `div`(350)→ `form.flex.flex-wrap`(350)→ `fieldset`(**384**)→ `div.max-w-3xl`(**326**) | `div`(350)→ `form.flex.flex-wrap`(350)→ `div.flex.flex-wrap`(350)→ `fieldset`(**384**) |
| ★ **为什么 `flex-wrap` 没用** | ★ **那两个 `form` / `div` 今天就已经写着 `flex-wrap`**(实测 `flexWrap: wrap`),而它们的 `min-content` **等于那一颗文件钮自己的 `min-content`(350)**。<br>☞ **换行分不开一个原子控件。** |
| ★ **`<fieldset>` 那一层是关键** | 它带着 UA 的 **`min-width: min-content`**(实测 `minWidth: "min-content"`)—— 于是它**压不到 350 + 内边距 32 + 边 2 = 384 以下**,而可用宽只有 **326**。**384 − 326 = 58**,页面因此宽到 417。 |

### 3.2 ★★ 四个候选,在【同一棵 DOM 上】逐个注入再量 —— 而委托书首选的那一个是无效的

> **Tim T3 的原话:「先加 `max-w-full`;如果到不了 0,再换成 `w-full`。」**
> ☞ **本刀没有猜,把四个都试了一遍**(`--task=t3try`,每次注入后等 500ms 再读,读完复原)。

| 候选 | `/finance/company` 整页溢出 | `/me` | 那颗钮的宽 | 判定 |
|---|--:|--:|--:|---|
| (原样) | 27 | 27 | 350 | —— |
| ★ **`max-w-full`** | ★ **27** | ★ **27** | 350 | ★★ **一点作用都没有** |
| ★ **`w-full`** | ★ **0** | ★ **0** | **292** | ✅ **用的是这一个** |
| 两个一起 | 0 | 0 | 292 | 与 `w-full` 逐字相同 |
| 给父元素 `min-width: 0` | 27 | 27 | 350 | 也没用 |
| **复原之后** | **27** ✓ | **27** ✓ | 350 | ★ 试打**没有留下残留** |

★★ **`max-w-full` 为什么无效,机制:**
`max-width: 100%` 是一个**百分比**,而在**内在尺寸(intrinsic sizing)计算**里,
对着一个不确定的包含块,百分比 `max-width` **当 `none` 处理** ——
于是它挡不住 `<fieldset>` 那条 `min-width: min-content` 的链。
`width: 100%` 才把**使用宽**压到 292。

☞ **这一条值得记:委托书给的首选修法是一个【没有被量过】的猜测,而量它花了不到两分钟。**
已写进 `AGENTS.md`「一次修法被判成【合法】,而没有人去看那个容器今天是不是已经在换行」那一节。

### 3.3 改了什么

两个**调用点**上各加一个类,**其余一个字节都没动**:

```jsx
className={`${CONTROL_FILE_BUTTON} w-full`}
```

* ★ **按内容定位,不按行号** —— 转换器靠 `type="file"` + `name="logo"` / `name="avatar"` 找到那一个开标签,并断言**全树只匹配到一个**。
* ★ **类名是一个完整的字面量**(`w-full` 写在模板串里,不是拼出来的)—— Tailwind 的扫描器读的是字面文本。
* ★ **`control-style.ts` 一个字节没改**;字体 / 字号 / 内边距**都没动**;
* ★ **全树另外 6 处 `<input type="file">` 一个都没碰**(`/settings/import` · 三份 `AttachmentsPanel` · `FinanceAttachmentsPanel` · `/finance/bank/import`)。
