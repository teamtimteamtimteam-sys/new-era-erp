### 2.5 孤儿 `check-css-declarations.mjs` —— **按 R-Q3 交回,没有自己接**

R-Q3 写的是「接进构建链……或者**不好办就停下来交回**」。**它属于后者,而且不是"不好办",是接不进去:**

* 它要 **`<before-dir> <after-dir>` 两个参数**,各指一棵带 `.next/static/chunks` 的**构建产物树**;
  不带参数时 **`OWN_EXIT=2`**,印 `用法:node scripts/check-css-declarations.mjs <before-dir> <after-dir>`。
* **`npm run build` 只产出其中一棵**,另一棵(before)**没有任何机制保留**。
  接进构建链要先发明一套构建产物留存机制 —— 那是另一刀,而且它会改变构建的形状。
* 它不是一支被忘掉的检查,**它是一支差分工具**:BRAND-1 用它证过一次「187 页没有变」,之后零调用。

### 2.6 实例 4(`check-confirm-subject`)—— 那个数变成了什么

**`58 处 subject / 57 个 JSX 开标签` → `57 / 57`**;扫到的文件 **52 → 51**。

1. 判据 `\bsubject\s*=` → **`(?<![-\w$])subject\s*=`**(`\b` 在连字符后面成立,于是

   **`useConfirm` 那一支单独计数** —— 并进来数就等于给断言重新开一个只能变大的方向。

### 2.7 实例 F(`survey-conflated-booleans`)—— 钉住的是**结构不变量**,不是那个会漂的 74

原来三条断言的说明写着「两条路必须**互相看得见**」,实际断言的只是**两边都不为空**:
实跑 **78 / 5,74 个文件的差额照常通过**。

★ **查下去发现的东西比差额本身更要紧:交叉核对那条臂只扫 `&&`**(逐字符找 `&&` 然后 `idx += 2`),

交叉核对必须命中,一个都不许漏**;`||` 那一半按名列在 `OR_ONLY_KNOWN` 里,
**名单两个方向变动都要红**。
