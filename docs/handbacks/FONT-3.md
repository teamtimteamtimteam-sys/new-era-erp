## 3 · ★★ Q16 的机制,一段话 ★★

> 共享字号写成 **`TABLE_TEXT = 'text-[15px]'`,定义在 `table-style.ts` 一处**,并在两个组件的
> **每一个格子上排在 `cn()` 链的最后**。`cn()` 是 `twMerge(clsx(…))`,而 tailwind-merge
> **让同一族里【后面】那一个类赢** —— `text-[15px]` 与调用点的 `text-sm` / `text-xs` /
> `text-[11px]` 同属 font-size 一族,于是组件那一个赢;`text-[color:var(--brand-text)]`
> 属于**字色**族,两条都留着。★ **选这个机制,而不选另外两个,各有一条量过的理由:**
> ① **不写 `@layer base` 的 `td { font-size: 15px }`** —— Tailwind v4 的层序是
> theme → base → components → utilities,`app/globals.css` 自己那段注释白纸黑字记着
> 「**它压不过工具类**」是刻意的;☞ 一条 base 规则会**输给每一个调用点的 `text-xs`**,
> **item i 一处都修不掉**。② **不去剥 `c.className` 里的字号 token** —— 那要在组件里
> 再写一支 class 串解析器(仓库里的第二份会漂的定义),而且它会**悄悄吃掉**一个
> 调用点在源码里还看得见的类;排到最后只改一行,而且**调用点那 294 个字号类一个都不删**
> (Q15)。③ **只搬【字号】那一个 token** —— `font-medium` 留在原处,所以一个调用点写的
> `font-semibold` / `font-bold` **照旧赢**:**这一刀不裁字重。**

★ **实测(tailwind-merge 3.6.0,本仓库这一份;脚本 `/tmp/font3/twm-r2.mjs`):**

| 输入 | 输出 |
|---|---|
| `twMerge('text-xs', 'text-[15px]')` | `text-[15px]` |
| `twMerge('text-sm', 'text-[15px]')` | `text-[15px]` |
| `twMerge('text-[11px]', 'text-[15px]')` | `text-[15px]` |
| `twMerge('text-[color:var(--brand-text)]', 'text-[15px]')` | ★ **两条都在** |
| `twMerge('text-sm font-semibold', 'text-[15px] font-medium')` | ⚠ **`font-semibold` 被吃掉** ☞ **所以只搬字号** |

### 9.1 一趟【141 / 141 全部 ok】的读数,量到的是登录页

### 9.2 一支扫描器的【切词】那一层,可以和它的【读取】那一层不一样瞎

round 1 数「右对齐、还没有 `tabular-nums` 的站点」时,把每个站点的 `className` **按空白切成 token**。

`text-right` 前面粘着一个 `'`,于是那个 token **不叫 `text-right`,它叫 `${'text-right`**。
★ **其中 3 个在 Tim 自己走查过的 `/finance/trial-balance` 与资产负债表上。**

☞ **处置:两种切法都跑一遍并排报**(宽切把 `'` `` ` `` `+` `{` `}` `(` `)` 也当分隔符);
两个数不一样,差集就是要读的那几行。
⚠ **还有一半:落地的时候不要按【行号】去对两支量具的名单** —— JSX 开标签的行号与 token 自己的
行号不是同一个数。第一版就是这么把 61 又变回 54 的。**按行区间对。**

### 9.3 一个「不一致」的计数,可以数进【屏幕上根本没有字】的那几格

「57 张表头不齐全修好」量下来剩 5 张过不去,而那 5 张剩的那一格**没有字**:

☞ **两条处置都做了:** ① 报这类计数时把「其中几格不渲染文字」一起报;
